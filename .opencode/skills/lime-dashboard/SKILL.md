# Lime Dashboard 设计语言

源自设计参考图（SaaS dashboard 视觉体系）的完整设计语言。参考图强调色为 Lime Green（#C7F33C），本项目中**色位映射为 Signal Blue（#1677ff）**——语言与品牌色无关，强调色是唯一可替换槽位。

## 核心气质

干净、现代、高级的"白板感"：内容全部以白色卡片浮在浅灰画布上，靠填充色差异分层，**零阴影、零描边**。黑白灰构成 95% 的画面，强调色只标记"唯一重要的东西"（当前值、推荐理由、选中态）。

## 色彩

| 角色 | 值 | 用途 |
|---|---|---|
| 画布 Canvas | `#f2f3f5` | 页面底色，卡片之间的间隔色 |
| 卡片 Surface | `#ffffff` | 所有内容容器，与画布形成分层 |
| 墨 Ink | `#1a1a1a` | 标题、数字、价格、黑色按钮底色 |
| 灰 Slate | `#505259` | 正文、次级信息 |
| 哑 Muted | `#888b94` | 占位、说明、弱化文字 |
| 强调 Accent | `#1677ff`（本项目的 Signal Blue，参考图为 Lime `#C7f33c`） | **仅**数据高亮：浅色 chip、选中态、关键值标记 |
| 强调淡 Pale | `#e6f4ff` | 强调色的浅色填充底（chip 背景） |

**规则：强调色覆盖率 ≤5%**（比常规主色更稀疏）。价格、关键数字、按钮**不是**强调色的领地——它们用墨黑。

## 字体排印

- **展示数字**：36–48px（750 稿）、600 字重、`tabular-nums`，墨黑色。号码、价格、统计值是页面的视觉主角。
- **标题**：36px / 600 / 墨黑，直接落在画布上（无卡片包裹的区块头）。
- **正文/说明**：28px / 400 / 灰（Slate）。
- **标签/chip 文字**：22px / 400。
- 字重只用 400 / 500 / 600；层级靠字号与颜色，不靠更多字重。

## 几何

- **卡片圆角**：32px（750 稿 = 16px @375），大而柔和。
- **按钮/搜索框/导航 chip**：**全圆角 pill**（border-radius: 999px）——本语言中 pill 只属于交互控件。
- **圆形按钮**：56px 直径（750 稿），白底 + 发丝线描边 + 墨色箭头图标，用于区块级导航（查看更多）。
- **chip（非交互标签）**：32px 高、4px 圆角、浅色填充。
- **无阴影、无卡片描边**；卡片与画布仅靠填充色差异区分。

## 组件配方

### 区块头（Section Header）
36px/600 墨黑标题直接落在画布上，右侧放圆形箭头按钮（56px 白底 + 发丝线 + 墨色 ↗）。不使用文字链接式"查看更多"。

### 卡片（Card）
白底、32px 圆角、32px 内边距、无阴影无描边。内容自上而下：小号灰标签 → 大号墨黑数字 → 次级信息行 → 底部（价格/动作）。卡片之间用画布色间隔（≥16px），卡片内不用分割线。

### 统计卡（Stat Card）
标签（灰）+ 大数字（墨黑 600）+ 可选强调 chip（淡底 + 深色文字）。仅当高亮值是"当前最重要的那个"时才上强调色。

### 主按钮 pill
Signal Blue 底（#1677ff，本项目的品牌色）+ 白字 + 全圆角，按压态深蓝（#0958d9）。卡片内主动作的唯一形态（如"选号"）。小尺寸：44px 高、22px 字、左右内边距 20px。

### 搜索 pill
全圆角白色长条（96px 高）：左侧浅灰占位文字（28px，Muted），右端内嵌黑色圆形搜索按钮（64px 直径 + 白色图标）。

### chip
32px 高、4px 圆角、左右内边距 12px。高亮 chip：淡蓝底（Pale）+ 深蓝文字（#0958d9）；普通 chip：浅灰底（#f2f3f5）+ 灰文字（Slate）。

## 布局

- 页面 = 浅灰画布 + 自上而下的卡片序列；区块头直接在画布上（不用白色区块包裹内容）。
- 轮播也做成**内嵌卡片**（左右留 32px 边距、32px 圆角），而不是通栏色块。
- 推荐位用横向滑动卡片（宽 520px），列表用整行卡片（左右 32px 边距、行距 16px）。
- 间距阶梯（750 稿）：8 / 12 / 14 / 16 / 18 / 24 / 32；卡片宽松（32 内边距），行内紧凑。

## 细节与禁忌

- **Do** 数字用 `tabular-nums`；大号数字是视觉锚点。
- **Do** 强调色只出现在：推荐理由 chip、选中态、最多一个关键值。
- **Do** 黑白灰优先，用填充色分层而不是线或影。
- **Don't** 给卡片加阴影或描边（参考图的"白板感"全靠无框卡片）。
- **Don't** 用强调色做价格或数据数字（本语言中数字/价格是墨黑；强调色留给行动与高亮）。
- **Don't** 大面积渐变、玻璃拟态、发光——这套语言靠克制取胜。
- **Don't** 在卡片里再放分割线列表；需要分组就拆卡片。

## 小程序适配（本项目）

- 业务样式按 750 稿写 px（Taro 转 rpx）；组件定制走 NutUI CSS 变量，不覆盖 `nut-*` 类。
- 强调色由 `src/styles/theme.scss` 的 CSS 变量提供；本语言只改变组件级样式组织，不改主题变量。
- 与 DESIGN.md 的关系：本 SKILL 为首页/卡片型页面的具体设计语言，DESIGN.md 中的全局规则（无渐变文字、无 nut-* 覆盖、间距阶梯）仍然生效；pill 形状仅用于按钮/搜索/导航 chip。
